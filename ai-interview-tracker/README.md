# AI Interview Tracker 🚀

A full-stack web application designed to help users track job applications and improve interview performance through automated interview feedback.

## ✨ Features

- Track job applications
- Add company and job role details
- Manage application status
- View applications in a professional dashboard
- Monitor application statistics
- Practice interview questions
- Receive an interview score
- View strengths and areas for improvement
- Get personalized interview suggestions

## 🛠️ Technologies Used

### Frontend

- React
- JavaScript
- HTML
- CSS
- Vite

### Backend

- Node.js
- Express.js
- REST API
