## 📌 Overview

AI Interview Tracker is an AI-powered full-stack application designed to help students and job seekers manage their complete interview preparation journey.

The platform allows users to track applications, record interview experiences, analyze performance, and receive personalized improvement suggestions.

---

## 🎯 Problem Statement

Candidates applying for multiple opportunities often face difficulties in:

- Tracking job applications
- Managing interview rounds
- Understanding interview performance
- Identifying skill gaps
- Improving preparation strategy

AI Interview Tracker provides a centralized solution to organize, analyze, and improve the interview journey.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/prathibha2197/AI-Interview-Tracker.git
```

## Backend Setup

```bash
cd backend
npm install
npm start
```

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
